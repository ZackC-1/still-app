# Platform marks

Locally hosted vector marks used to identify the illustrated platform cards in the homepage animation. Retrieved September 24, 2026. Artwork is retained as downloaded; the animation scales it proportionally.

- `youtube-shorts.svg`: [YouTube Shorts icon](https://commons.wikimedia.org/wiki/File:Youtube_shorts_icon.svg), original YouTube mark, vector by Premeditated. Source page labels it PD-textlogo.
- `instagram-reels.svg`: [Instagram Reels logo](https://commons.wikimedia.org/wiki/File:Instagram_Reels_logo.svg). Source page labels it public domain/ineligible for copyright.
- `tiktok.svg`: [TikTok icon](https://commons.wikimedia.org/wiki/File:Tiktok_icon.svg), Editantpv and Ionic Team. Source page labels it CC0.

These identify third-party services, not a partnership or endorsement. Trademarks belong to their respective owners.
