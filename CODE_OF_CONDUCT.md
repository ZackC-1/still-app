# Code of Conduct

Still's project spaces should be useful, respectful, and focused on the work.

## Expected behavior

- Be direct and constructive.
- Assume contributors are trying to improve the project.
- Keep discussion tied to the issue, pull request, or design decision.
- Respect user privacy, security reports, and unpublished release details.

## Unacceptable behavior

- Harassment, threats, or discriminatory language.
- Publishing private information, credentials, exploit details, or user data.
- Repeated off-topic comments after maintainers ask for focus.
- Bad-faith issue spam or intentionally misleading reports.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or restrict participation when behavior harms the project or its users.

Report conduct concerns to the repository maintainer through GitHub. Security concerns should follow [SECURITY.md](SECURITY.md).
