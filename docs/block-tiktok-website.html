How to block the TikTok website in Safari, Chrome and Firefox

Still blocks tiktok.com, including its web profiles and messages. It works in Safari on iPhone, iPad and Mac, and in Chrome and Firefox on desktop. Blocking is free and needs no account.

What the TikTok website block includes

Still blocks the whole TikTok website. This differs from its YouTube Shorts and Instagram and Facebook Reels controls, which preserve the useful parts of those websites. TikTok web profiles and messages are blocked too.

Still cannot block the native TikTok app. On iPhone and iPad it works only on websites opened in Safari. It does not support Android. Read why browser extensions cannot block native iPhone apps before installing.

Set up the TikTok website block

  1. Install Still for your browser using the store links below. On iPhone, iPad and Mac, the Still app includes the Safari extension.
  2. Enable the extension and allow it access to tiktok.com. The setup guide for your device and browser explains the permission steps.
  3. Open Still. Turn on the main switch and the TikTok control.
  4. Reload the TikTok website in that browser to check the block.

If TikTok still loads

Confirm that you opened the website in the browser where Still is installed. Check its website permission and both switches. On iPhone and iPad, use Safari rather than the native app or another browser. Reload after changing permissions or settings. Get troubleshooting help if it still loads.

A control you can change

Still is not a hard lock or parental-control system. You can turn off its TikTok control, disable the extension or revoke its permission. Your settings are saved locally; optional sign-in enables free sync across supported browsers and devices.
