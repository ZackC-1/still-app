Still

Set up Still

Choose your device and browser, then follow the steps below.

Still removes YouTube Shorts and Instagram and Facebook Reels, and blocks the TikTok website, for free on every supported surface. No account is needed. Signing in is optional and only syncs your settings. You turn Still on once in each browser.

  • Mac — Safari
  • Mac — Chrome
  • Mac — Firefox
  • Windows or Linux — Chrome
  • Windows or Linux — Firefox
  • iPhone — Safari
  • iPad — Safari

On iPhone and iPad, use the websites in Safari. Still does not block inside the native YouTube, Instagram, Facebook, or TikTok apps, or in mobile Chrome or Firefox.

Mac — Safari

  1. Install Still from the Mac App Store and open it.
  2. On Turn on Still in Safari, click Open Safari Settings. Safari opens at Extensions.
  3. Switch on Still. Allow it on Instagram, Facebook, YouTube, and TikTok. If Safari did not open, choose Safari → Settings → Extensions yourself.
  4. Quit Safari (⌘Q) and reopen it. If you use Safari profiles, also check Settings → Profiles → your profile → Extensions.
  5. Back in Safari, click Still’s toolbar button. Check that blocking works.

If Still is turned off later, the Still app shows Turn on Still in Safari when you open it. Click Open Safari Settings to switch it back on.

For Safari menu and permission details, see Apple’s Mac extension instructions.

Mac — Chrome

  1. Open the Chrome profile you use for browsing. The Still Mac app provides the Safari extension; Chrome needs its own extension.
  2. Visit Still in the Chrome Web Store. Choose Add to Chrome and confirm with Add extension.
  3. Still opens a setup page. Do the first step, Allow Still on supported sites, and confirm in Chrome.
  4. Pin Still: click the puzzle piece in the toolbar, then the pin next to Still.
  5. Click Still. The main switch and all four websites are on; turn off any you do not want.
  6. If blocking does not start, open Extensions → Manage extensions → Still → Details and set Site access to allow the four sites. Reload them, then check blocking.

To see the setup page again, open Still’s settings and choose Setup guide. Install Still in each Chrome profile you use.

See Google’s extension installation and permission instructions.

Mac — Firefox

  1. Open Firefox. The Still Mac app provides the Safari extension; Firefox needs its own add-on.
  2. Visit Still on Firefox Add-ons. Select Add to Firefox and confirm the permissions.
  3. Still opens a setup page. Do the first step, Allow Still on supported sites, and confirm in Firefox.
  4. Pin Still: click the puzzle piece in the toolbar, then the gear next to Still, then Pin to toolbar.
  5. Click Still. The main switch and all four websites are on; turn off any you do not want.
  6. Reload the social websites you already had open, then check blocking. If Still is disabled, open Add-ons and themes → Extensions and enable it.

To see the setup page again, open Still’s settings and choose Setup guide.

See Mozilla’s instructions for installing add-ons and toolbar access and permissions.

Windows or Linux — Chrome

  1. Open the Chrome profile you normally use. Visit Still in the Chrome Web Store.
  2. Select Add to Chrome, then Add extension.
  3. On Still’s setup page, do the first step, Allow Still on supported sites, and confirm in Chrome.
  4. Pin Still: click the puzzle piece in the toolbar, then the pin next to Still.
  5. Click Still. The main switch and all four websites are on; turn off any you do not want.
  6. If blocking does not start, review Manage extensions → Still → Details → Site access. Reload open social websites and check blocking. Each browser profile needs Still installed.

You do not need an Apple device or the Still Mac app to use Still in Chrome.

Windows or Linux — Firefox

  1. Open Firefox and visit Still on Firefox Add-ons.
  2. Select Add to Firefox, then confirm the permissions.
  3. On Still’s setup page, do the first step, Allow Still on supported sites, and confirm in Firefox.
  4. Pin Still: click the puzzle piece in the toolbar, then the gear next to Still, then Pin to toolbar.
  5. Click Still. The main switch and all four websites are on; turn off any you do not want.
  6. Reload the social websites, then check blocking. To re-enable Still later, use Add-ons and themes → Extensions.

You do not need an Apple device or the Still Mac app to use Still in Firefox.

iPhone — Safari

  1. Install Still from the App Store and open it. Continue to Turn on Still in Safari.
  2. Tap Open Settings.
  3. iOS 26.2 or later: Settings opens on Still’s Safari extension page. Turn on Allow Extension, then allow Instagram, Facebook, YouTube, and TikTok.
  4. Earlier iOS: Settings opens on Still’s own page. Go back, then choose Apps → Safari → Extensions → Still (on iOS 17 or earlier, Safari → Extensions → Still). Turn on Still, then allow the four websites.
  5. Close Safari, then reopen it.
  6. Return to Still and tap I’ve turned it on. On iOS 26.2 or later, Still confirms it for you.
  7. In Safari, open one of the websites. Use the Page Menu to reach Still. Check blocking in Safari, not in a native app.

If Still is turned off later, on iOS 26.2 or later the Still app shows Turn on Still in Safari when you open it. Tap Open Settings to switch it back on. On earlier iOS, repeat the steps above.

See Apple’s iPhone Safari extension instructions.

iPad — Safari

The steps are the same as on iPhone: open the Still app, tap Open Settings on Turn on Still in Safari, turn on Allow Extension, allow the four websites, then close and reopen Safari. On earlier iPadOS, go back and choose Apps → Safari → Extensions → Still (iPadOS 17 or earlier: Safari → Extensions → Still).

Installing Still on an iPhone does not finish setup on an iPad. Install and turn on Still on the iPad too, then check blocking.

Check each website

Keep the main Still switch on, then enable the corresponding website control:

  • YouTube Shorts: open YouTube. Shorts entry points should disappear, and a Shorts link opens in the normal player. Regular videos and search keep working.
  • Instagram Reels: open Instagram. Reels navigation should disappear; normal posts and profiles remain usable. A Reel someone sends you still plays, but Still stops the next Reel and the Reels feed.
  • Facebook Reels: open Facebook. Reels navigation should disappear; normal posts remain usable. A Reel someone sends you still plays, but Still stops the next Reel and the Reels feed.
  • TikTok website: open TikTok. The website is replaced by Still’s blocking message.

After enabling the extension, granting permissions, or changing a setting, reload any website that was already open.

Optional: sync your settings

  1. On iPhone, iPad, or Mac, sign in from the Still app’s Settings sync card. In Chrome or Firefox, sign in on Still’s setup page, popup, or settings.
  2. Use the same email address on each device and browser. Enter the code from your email; check Spam or Junk if it is missing.
  3. Check the email shown under Settings sync, and wait for Synced with your account.
  4. Change a website switch on one device and check it on another. If a device is offline, Still keeps its local settings and syncs when it reconnects.

Signing in syncs your Still settings. It does not install Still, turn on Safari, or grant browser permissions on your other devices, and blocking never needs an account.

Optional: Still Pro

Still Pro is a one-time purchase that adds optional extras, such as hiding YouTube comments or Instagram Explore. They start off. Everything in this guide works without it. Choose Get Still Pro in the Still app, or in Still’s settings in Chrome and Firefox, where a purchase needs a Still account.

If blocking is not working

  • Check the browser and profile you are actually using. Chrome, Firefox, and Safari have separate installations. Avoid running duplicate Still extensions in the same profile.
  • Check that the extension, main Still switch, and relevant website switch are all enabled. In Safari, open the Still app: on a Mac, or an iPhone or iPad on iOS 26.2 or later, it says when Still is off and how to turn it back on.
  • Check permission for the current website, then reload it.
  • If you browse privately, enable Still for private browsing in that browser’s extension settings. On iPhone and iPad, that switch is on Still’s Safari extension page in Settings. Test in a normal window first.
  • If YouTube, Instagram, or Facebook changes and something slips through, contact Still support with your device, browser, Still version, and the affected page type. Do not send login codes or account credentials.
