Set up Still

Choose your device and browser, then follow the steps below.

This guide covers Still 2.0. Store updates may arrive at different times. In 2.0, all four website controls work without an account; signing in adds settings sync. Browser permissions must still be enabled on each device.

  • Mac — Safari
  • Mac — Chrome
  • Mac — Firefox
  • Windows or Linux — Chrome
  • Windows or Linux — Firefox
  • iPhone — Safari
  • iPad — Safari

On iPhone and iPad, use the websites in Safari. Still does not block videos inside native YouTube, Instagram, Facebook, or TikTok apps, or in mobile Chrome or Firefox.

Mac — Safari

  1. Install Still from the App Store, then open the Still app.
  2. Open Safari. In the menu bar, choose Safari → Settings → Extensions. On older macOS versions, Settings is called Preferences.
  3. Find Still and select its checkbox. If you use Safari profiles, also check Settings → Profiles → your profile → Extensions.
  4. Select Still, then Edit Websites if shown. Allow access to youtube.com, instagram.com, facebook.com, and tiktok.com. If a site is not listed, visit it and respond to Safari’s permission prompt.
  5. Click Still in Safari’s toolbar, or open the Still app. Turn on the main switch and the website controls you want.
  6. Reload any social websites that were already open, then check that blocking works.

For Safari menu and permission details, see Apple’s Mac extension instructions.

Mac — Chrome

  1. Open the Chrome profile you use for browsing. The Still Mac app provides the Safari extension; Chrome needs its own extension.
  2. Visit Still in the Chrome Web Store. Choose Add to Chrome and confirm with Add extension.
  3. Open Chrome’s Extensions menu (the puzzle icon). Click the pin beside Still to keep it in your toolbar.
  4. Click Still. Turn on the main switch and the website controls you want.
  5. If website access is restricted, open Extensions → Manage extensions → Still → Details and review Site access. Allow the four supported websites, then reload them.
  6. Check blocking. Repeat installation in any other Chrome profile where you want Still.

See Google’s extension installation and permission instructions.

Mac — Firefox

  1. Open Firefox. The Still Mac app provides the Safari extension; Firefox needs its own add-on.
  2. Visit Still on Firefox Add-ons. Select Add to Firefox and confirm the requested permissions.
  3. Open Firefox’s Extensions menu (the puzzle icon). If Still is not already in the toolbar, use its menu and choose Pin to Toolbar.
  4. Click Still. Turn on the main switch and the website controls you want. Grant access if Firefox asks to let Still run on a supported website.
  5. Reload the social websites you already had open, then check blocking. If Still is disabled, open Add-ons and themes → Extensions and enable it.

See Mozilla’s instructions for installing add-ons and toolbar access and permissions.

Windows or Linux — Chrome

  1. Open the Chrome profile you normally use. Visit Still in the Chrome Web Store.
  2. Select Add to Chrome, then Add extension.
  3. Use Chrome’s puzzle-icon Extensions menu to pin Still, then open it from the toolbar.
  4. Turn on the main Still switch and your chosen website controls. If access is restricted, review Manage extensions → Still → Details → Site access and allow the supported websites.
  5. Reload open social websites and check blocking. Each browser profile needs Still installed and enabled.

You do not need an Apple device or the Still Mac app to use Still in Chrome.

Windows or Linux — Firefox

  1. Open Firefox and visit Still on Firefox Add-ons.
  2. Select Add to Firefox, then confirm the permissions.
  3. Find Still using Firefox’s puzzle-icon Extensions menu. Use its menu to Pin to Toolbar if needed.
  4. Open Still, turn on the main switch and your chosen website controls, and allow access when Firefox prompts on a supported site.
  5. Reload the social websites, then check blocking. To re-enable Still later, use Add-ons and themes → Extensions.

You do not need an Apple device or the Still Mac app to use Still in Firefox.

iPhone — Safari

  1. Install Still from the App Store and open it once.
  2. Open the iPhone Settings app, then Apps → Safari → Extensions → Still. On iOS 17 or earlier, start with Settings → Safari.
  3. Turn on Allow Extension. Set website access to Allow for YouTube, Instagram, Facebook, and TikTok where listed.
  4. Open one of those websites in Safari. If permission is still needed, use Safari’s Page Menu → Manage Extensions, enable Still, and allow it on that website. Repeat for the other sites you use.
  5. Open the Still app and turn on the main switch and the website controls you want.
  6. Return to Safari and reload the page. Check blocking in Safari, rather than opening a native social app.

See Apple’s iPhone Safari extension instructions.

iPad — Safari

  1. Install Still from the App Store and open it once.
  2. Open Settings → Apps → Safari → Extensions → Still. On iPadOS 17 or earlier, use Settings → Safari → Extensions.
  3. Enable Allow Extension and allow access to the four supported websites where listed.
  4. Open Safari and visit a supported website. Use its page or extensions menu to find Still, and approve website access if requested.
  5. In the Still app, turn on the main switch and your chosen website controls. Return to Safari, reload the website, and check blocking.

Installing Still on an iPhone does not finish setup on an iPad. Check that the app is installed and Safari permissions are enabled on the iPad too.

Check each website

Keep the main Still switch on, then enable the corresponding website control:

  • YouTube Shorts: open YouTube. Shorts entry points should disappear, while regular videos, search, and ordinary topic filters continue working.
  • Instagram Reels: open Instagram. Reels navigation should disappear; normal posts and profiles remain usable. A direct Reels page shows Still’s blocking message.
  • Facebook Reels: open Facebook. Reels navigation should disappear; normal posts remain usable. A direct Reel page shows Still’s blocking message.
  • TikTok website: open TikTok. The website is replaced by Still’s blocking message.

After enabling the extension, granting permissions, or changing a setting, reload any website that was already open.

Optional: sync your settings

  1. On Apple devices, sign in in the Still app. In Chrome or Firefox, sign in through Still’s popup or settings page.
  2. Use the same email address on each supported surface. Enter the code from your email; check Spam or Junk if it is missing.
  3. Check the email shown under Settings sync. Wait for Synced with your account. In the Safari extension, check that its settings match the Still app.
  4. Change a website switch on one device and check it on another. If a device is offline, Still keeps its local settings and syncs when it reconnects.

Signing in syncs your Still settings. It does not install extensions or grant browser permissions on your other devices.

If blocking is not working

  • Check the browser and profile you are actually using. Chrome, Firefox, and Safari have separate extension installations. Avoid running duplicate Still extensions in the same profile.
  • Check that the extension, main Still switch, and relevant website switch are all enabled.
  • Check permission for the current website, then reload it.
  • If you browse privately, enable Still for private browsing in that browser’s extension settings. Test in a normal window first.
  • If YouTube, Instagram, or Facebook changes and something slips through, contact Still support with your device, browser, Still version, and the affected page type. Do not send login codes or account credentials.
