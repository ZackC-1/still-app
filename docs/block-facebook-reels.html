How to block Facebook Reels without blocking Facebook

Remove Facebook Reels from the website while keeping ordinary posts and messages available. Still works in Safari on iPhone, iPad and Mac, and in Chrome and Firefox on desktop.

What Facebook Reels blocking does

Still removes Reels surfaces and stops the Reels feed on facebook.com. It keeps the rest of Facebook available. Facebook Reels removal is free and requires no account or purchase.

On iPhone and iPad, open Facebook in Safari. A Safari extension cannot change the native Facebook app. See how browser extensions differ from native iPhone apps.

Enable Still for Facebook

  1. Install Still for your browser using the store links below. Install it separately in each browser you use.
  2. Enable the extension. In Safari, allow Still access to facebook.com when asked. Follow the device and browser setup instructions if you need help finding the permission controls.
  3. Open Still and turn on its main switch and the Facebook control.
  4. Reload Facebook. Check that the Reels surfaces and feed are removed while ordinary posts remain available.

If Reels still appear

Check that you are browsing facebook.com in the browser where Still is installed. On mobile, use Safari. Confirm website permission, the main Still switch and the Facebook control, then reload the page. If the problem continues, contact Still support with your device, browser, Still version and affected page type.

Keep your choices across browsers

Your settings stay on your device without an account. Optional sign-in with the same email on your supported devices enables free settings sync. Browser permissions still need to be enabled on each device.
