The TikTok blocked page, the only screen Still shows inside a website: mark, "TikTok stays closed.", Open TikTok this time.

```jsx
<TikTokBlocked host="browser" onOpenOnce={allowThisTab} onOpenSettings={openOptions} />
```

- Allowance: this living tab only, until it closes or the browser restarts. Not saved, not synced, not inherited by other tabs or embedded players.
- "Reload page" only when it's genuinely needed; never reload automatically.
